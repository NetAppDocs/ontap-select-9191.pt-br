= ONTAP Select VMware vCenter server no ESXi
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Você deve definir uma conta de servidor vCenter e associá-la a uma função que contenha os privilégios administrativos necessários.


NOTE: Você também precisa do nome de domínio totalmente qualificado ou endereço IP do servidor vCenter que gerencia os hosts do hipervisor ESXi onde ONTAP Select está implantado.
