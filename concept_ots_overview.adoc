= Saiba mais sobre ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select é uma versão somente em software do ONTAP que você pode implementar como uma máquina virtual em um host hipervisor. Ele complementa o conjunto de ofertas principais do AFF e do FAS ONTAP, bem como outras opções somente de software, como o Cloud Volumes ONTAP.

ONTAP Select converte unidades de disco internas, NVMe, SSD ou HDD, e armazenamento externo em array, em um sistema de storage flexível com muitos dos mesmos benefícios oferecidos pelos sistemas de storage ONTAP dedicados. Você também pode implementar ONTAP Select em novos servidores ou em sua infraestrutura de servidores existente. ONTAP Select é fácil de gerenciar e utiliza o mesmo software de gerenciamento que as soluções baseadas em ONTAP, o que significa redução da sobrecarga operacional e das necessidades de treinamento.

ONTAP Select se adapta às suas necessidades de consumo de capacidade com dois modelos de licenciamento complementares — Capacity Tiers e o totalmente flexível Capacity Pools. Ambos os modelos de licenciamento permitem aumentar a capacidade em incrementos de apenas 1TB. Por exemplo, você pode começar com alguns terabytes e adicionar capacidade dinamicamente à medida que seu projeto cresce. Se você estiver usando Capacity Pools, pode redistribuir a capacidade como achar melhor quando seu projeto for concluído.

ONTAP Select está integrado a estruturas de gerenciamento de nuvem como VMware vSphere e Kernel-based Virtual Machine (KVM). Isso ajuda a acelerar a implantação de novos projetos, como serviços de arquivos, diretórios pessoais, ambientes de desenvolvimento de software e testes de aplicativos.

SnapMirror software permite que você mova dados entre o armazenamento ONTAP na nuvem híbrida, facilitando o acesso aos seus dados onde você quiser. Por exemplo, você pode criar um ambiente rapidamente para testar uma ideia. Posteriormente, você pode mover o projeto para uma plataforma de storage dedicada para implantação em produção ou torná-lo mais acessível na nuvem como parte de um fluxo de trabalho de desenvolvimento.



[[software-defined-storage]]
== Armazenamento definido por software

A implementação e a entrega de serviços de TI por meio de software permitem que os administradores provisionem recursos rapidamente, com uma velocidade e agilidade antes impossíveis. À medida que os data centers modernos migram para uma arquitetura de infraestrutura definida por software (SDI), é possível separar os ativos de TI mais valiosos da infraestrutura física subjacente, proporcionando flexibilidade, escalabilidade e programabilidade.

Em um mundo dominado por commodities, onde os dados estão fragmentados em silos de armazenamento de conexão direta (DAS), o acesso e o gerenciamento de dados tornaram-se problemas mais complexos. O armazenamento definido por software (SDS) surgiu como uma parte importante do cenário de SDI para solucionar esses e outros problemas.

ONTAP Select é a solução NetApp para o mercado de SDS. ONTAP Select traz recursos de gerenciamento de storage empresarial para o data center definido por software e estende a arquitetura NetApp Data Fabric para casos de uso extremos na borda, incluindo a Internet das Coisas (IoT) e servidores táticos.



[[two-software-components]]
== Dois componentes de software

ONTAP Select é composto por dois componentes de software principais:



[[ontap-select-node]]
=== Nó do ONTAP Select

Um ONTAP Select cluster é composto por um, dois, quatro, seis, oito, dez ou doze nós. Cada nó de cluster é implantado como uma máquina virtual separada e executa uma versão especialmente projetada do software ONTAP 9.



[[ontap-select-deploy-administration-utility]]
=== Utilitário de administração do ONTAP Select Deploy

O utilitário de administração Deploy é empacotado e instalado como uma máquina virtual Linux separada. Você deve usar o utilitário para implantar clusters ONTAP Select em um ambiente de produção. Uma versão atual da imagem do nó ONTAP Select é fornecida com o utilitário Deploy.


NOTE: O utilitário de administração Deploy não possui um número de versão separado. O Deploy tem o mesmo número de versão da respectiva versão do ONTAP Select. No entanto, cada atualização do utilitário Deploy dentro de uma versão específica do ONTAP Select possui um número de compilação exclusivo.

[[flexcache-write-back-with-ontap-select]]
== FlexCache write-back com ONTAP Select

O ONTAP Select suporta volumes de cache do FlexCache com write-back. O desempenho geral da instância do ONTAP Select é comparável ao de um sistema ONTAP básico.

FlexCache cache volumes com write-back têm os seguintes requisitos com ONTAP Select:

* Utilize ONTAP Select em uma instância média (8-core) ou grande (16-core).
* Utilize unidades de estado sólido com tecnologia NVMe. O armazenamento com tecnologia SAS apresenta desempenho inferior ao armazenamento com tecnologia NVMe para ONTAP Select.
* Teste o ONTAP Select para FlexCache write-back antes de iniciar a implantação. FlexCache write-back não é recomendado para um grande número de arquivos pequenos.


ONTAP Select não suporta FlexCache cache volumes com write-back em instâncias pequenas (4 núcleos). Além disso, ONTAP Select não suporta FlexCache origin volumes com write-back em instâncias pequenas, médias ou grandes.

link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["Saiba mais sobre o recurso de write-back do ONTAP FlexCache"^]



[[compare-ontap-select-and-ontap-9]]
== Compare ONTAP Select e ONTAP 9

Tanto o ONTAP baseado em hardware quanto o ONTAP Select oferecem soluções de storage empresariais. No entanto, como são projetados e implementados de forma diferente, cada um pode atender a diferentes requisitos de negócios e cenários de uso. Você deve se familiarizar com as principais diferenças entre as plataformas antes de planejar uma implantação do ONTAP Select.



[[different-ha-architecture]]
=== Diferente arquitetura de alta disponibilidade

Dependendo do número de nós que você definir em um cluster, ONTAP Select oferece um recurso de HA. Por exemplo, um cluster de quatro nós consiste em dois pares de HA. A arquitetura de HA usada com ONTAP Select é baseada em um modelo de storage não compartilhado. Ou seja, um nó em um par de HA não pode acessar diretamente o storage pertencente ao outro nó. Esse design pode afetar certas características operacionais do ONTAP Select.



[[capacity-licensing]]
=== Licenciamento de capacidade

ONTAP Select introduz um modelo de licenciamento baseado em consumo. Você deve adquirir uma licença com capacidade de storage para cada nó ou Capacity Pool compartilhado ao implementar um cluster ONTAP Select em um ambiente de produção. Utilizando o utilitário Deploy, você deve aplicar os arquivos de licença que estabelecem a capacidade de storage para os nós do cluster.



[[ontap-feature-licensing]]
=== Licenciamento de recursos ONTAP

Cada nó em um cluster ONTAP Select é automaticamente licenciado para usar vários recursos do ONTAP. Você não precisa instalar ou aplicar essas licenças de recursos manualmente.



[[ontap-features-not-supported-in-ontap-select]]
=== Funcionalidades do ONTAP não suportadas no ONTAP Select

Diversos recursos do ONTAP não são compatíveis com ONTAP Select. Na maioria dos casos, esses recursos exigem hardware específico que não está disponível no ambiente virtualizado do ONTAP Select.

* Atualizações automáticas para a Proteção Autônoma contra Ransomware (ARP)
+

NOTE: A partir do ONTAP Select 9.16.1, as atualizações manuais do ARP são suportadas e a licença do recurso ARP está incluída no NetApp License File (NLF).

* Gerenciadores de chaves em nuvem
* Espaço IP do cluster
+
Qualquer modificação no IPspace do cluster, incluindo a adição ou remoção de portas, VLANs (redes locais virtuais) ou grupos de agregação de links, não é suportada.

* Grupos de consistência em SnapMirror assíncrono
* Fibre Channel
+
Fibre Channel e Fibre Channel over Ethernet não são suportados.

* Monitores de saúde
+
O monitoramento de integridade tradicional usado em uma implantação ONTAP baseada em hardware é específico para os componentes de hardware subjacentes. Devido ao ambiente virtualizado usado com o ONTAP Select, os monitores de integridade não estão ativos.

* Grupos de interface
+
Grupos de interface não são suportados.

* Suporte para descarregamento de NIC
+
Devido ao ambiente virtualizado utilizado com ONTAP Select, o recurso de descarregamento de NIC não é suportado.

* NetApp unidades de criptografia de storage
* Propriedades da porta do ONTAP
+
A modificação das propriedades das portas ONTAP, incluindo velocidade, duplex e controle de fluxo, não é suportada.

* Processadores de serviço
* SVM-Migrate
* SnapLock Compliance
* SnapMirror active sync
* VMware HCX
