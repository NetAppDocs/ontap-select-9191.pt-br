= Acesse o software de avaliação ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Você pode acessar o link:https://mysupport.netapp.com/site/downloads/evaluation/ontap-select["Software de avaliação ONTAP Select"^] se for um cliente atual do ONTAP Select e tiver um direito ativo ou um NetApp Partner e quiser baixar uma nova licença de avaliação do Capacity Tiers.

Se você não se enquadra em nenhuma das opções acima e gostaria de experimentar ONTAP Select para avaliação, siga estas etapas para solicitar acesso ao download do software de avaliação.

.Sobre esta tarefa
* Esta instrução destina-se a vendas, parceiros e potenciais clientes da NetApp envolvidos com a NetApp.
* As licenças de avaliação do ONTAP Select Capacity Tiers são limitadas a 90 dias a partir da data de instalação.
+

NOTE: Não é possível estender uma licença de avaliação. Ao final dos 90 dias, a licença deixa de funcionar e você não pode acessar os dados associados.

* O software de avaliação contém todas as informações necessárias para baixar o utilitário de administração ONTAP Select Deploy e implantar um cluster.




[[step-1-register-for-an-account]]
== Passo 1: Cadastre-se para obter uma conta

Conclua o cadastro da conta NetApp, se necessário, e solicite o acesso do potencial cliente.

.Passos
. Crie uma nova conta ou saia de uma conta existente.
+
[role="tabbed-block"]
====
.Criar nova conta
--
Cadastre-se para obter uma conta no link:https://mysupport.netapp.com/site/user/registration["Site de suporte da NetApp"^] usando seu e-mail comercial.


NOTE: Contas de e-mail gratuitas, como gmail ou yahoo, não são aceitas.

Certifique-se de não estar conectado com a conta recém-criada.

--
.Conta existente
--
Se você já possui uma conta, acesse a link:https://mysupport.netapp.com/site/["Site de suporte da NetApp"^] e certifique-se de que não está conectado.

--
====
. Crie um caso de suporte não técnico para elevar os níveis de acesso a "prospect".
+
.. Selecione a aba *CASOS* e, em seguida, selecione *Criar casos não técnicos*
.. Selecione *Problema com o cadastro do usuário* como categoria de feedback.
.. Selecione *Criar caso*.
+
Preencha todas as informações necessárias e, na seção de comentários, escreva: "Meu endereço de e-mail comercial é <your-email-address>. Gostaria de obter acesso de prospect para baixar o software de avaliação do ONTAP Select."

+
Inclua o nome do seu contato da NetApp.

.. Selecione *Enviar*.






[[step-2-download-ontap-select-evaluation-software]]
== Etapa 2: Baixe o software de avaliação ONTAP Select

Após a sua solicitação de suporte ser analisada e aprovada, a equipe de suporte da NetApp notificará você usando o endereço de e-mail fornecido.

.Etapa
. https://mysupport.netapp.com/site/downloads/evaluation/ontap-select["Baixe o software de avaliação ONTAP Select"^].
+
O arquivo de licença de avaliação está localizado dentro do arquivo zip.

. Para cumprir os requisitos legais, é necessário link:https://mysupport.netapp.com/site/help["Abra um chamado de suporte"^] antes de obter acesso. Isso ajuda NetApp a manter o controle e a documentação adequados, ao mesmo tempo que fornece o software pronto para produção de que você precisa.
+

NOTE: NetApp fornece a versão "pronta para produção" do ONTAP Select, que não é uma versão de código aberto ou alternativa. O suporte está disponível apenas se você atualizar para uma licença de produção.



.Qual é o próximo passo?
Após a conclusão do download do software de avaliação, siga as instruções para baixar o utilitário de administração ONTAP Select Deploy e implantar um cluster.
